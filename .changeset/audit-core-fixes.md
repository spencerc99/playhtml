Fix a batch of cleanup, cursor, and listener bugs. `deleteElementData` now tears the element down like `removePlayElement` does, so its `onMount` cleanup runs and it stops writing to the deleted record. `can-mirror` and `can-hover` remove their listeners (and `can-mirror` its observer) when an element is removed or its handler is rebuilt. `element.reset()` on elements with a reset shortcut now restores the default data instead of doing nothing. `can-grow` shows the not-allowed cursor once an element reaches its maximum size. A play event listener or page data subscriber that throws is logged and no longer stops the remaining listeners. With `visibilityThreshold` set, other people's cursors no longer flicker on a scrolled page, and a cursor created inside a zone with its own `getCursorStyle` no longer keeps the global styles. Cursor chat shows `<` and `&` as typed. `listSharedElements()` reports `shared="ro"` as read-only, matching the runtime. playhtml no longer throws on startup when `localStorage` is blocked. Each element's random `--jiggle-delay` is applied again. Dev mode removes its stylesheet and restores the page margin on teardown. Pointer movement does less work per frame. Typing `/` or any other key into an input, textarea, or contenteditable region on the page no longer opens cursor chat or gets swallowed by it, and typing outside chat no longer sends a cursor update every 10 seconds. Tearing playhtml down removes `window.cursors` and restores the page's own cursor style, unless something newer has replaced them. A pending `setDataDebounced` write is dropped when its element is removed or deleted instead of landing afterwards, and one still pending when an element's handler is rebuilt goes through the current `onChange`. A play event listener that removes itself while handling an event no longer causes the next listener to miss that event.
