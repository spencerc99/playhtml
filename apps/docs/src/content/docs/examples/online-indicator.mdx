## Presence per reader

Each reader has a presence on this element: a value everyone can see, never
saved, gone when they leave. Yours starts at `defaultPresence`. `everyone` lists
everyone here right now, including you, each with their name and color and
their presence on this element:

```js
everyone.map((person) => person.presence.color);
```

`person.isMe` marks your own dot.

## Set your value

Call `setMyPresence` from a user event. It sets your whole value and reaches everyone
else right away:

```js
online.setMyPresence({ color: event.target.value });
```

See [people and presence](/docs/data/presence/) for page-wide presence and cursors.
