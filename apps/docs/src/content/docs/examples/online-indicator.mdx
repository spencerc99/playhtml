## Presence per reader

`presence` is your own value for this element. It is never saved, and it clears
when you leave. `everyone` lists everyone here right now, including you, each
with their identity and their current `presence`:

```js
everyone.map(({ user, presence }) => presence?.color ?? user.color);
```

A reader who hasn't set a value yet has no `presence`, so fall back to their
cursor color.

## Set your value

Call `setMyPresence` from a user event. It replaces your value and reaches everyone
else right away:

```js
online.setMyPresence({ color: event.target.value });
```

See [Presence](/docs/data/presence/) for page-wide presence and cursors.
