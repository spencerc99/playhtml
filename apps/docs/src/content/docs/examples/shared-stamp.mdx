## Point at the source

The homepage marks its stamp with `shared`:

```html
<!-- on playhtml.fun -->
<img id="stamp" src="playhtml-logo.png" can-spin shared />
```

Any other page, on any site, reads and writes the same rotation with
`data-source` and the same capability. Its markup and styles can be different:

```html
<!-- anywhere else -->
<img class="stamp" src="playhtml-logo.png" data-source="playhtml.fun#stamp" can-spin />
```

See [Shared elements](/docs/advanced/shared-elements/) for read-only sources and
the full `data-source` syntax.
