This guestbook keeps form drafts local and stores submitted entries in a
shared list. The write caps the list at 20 entries so persisted data stays
bounded.

## Keep drafts local

The textarea is normal local form state. Nothing is shared until the form
passes validation and submits.

Each accepted entry gets a unique `id`, prompt, and text:

```js
{
  id: crypto.randomUUID(),
  prompt: "building",
  text: "a shared drawing tool",
}
```

## Cap the shared list

Append and trim in the same mutator:

```js
setData((draft) => {
  draft.entries.push(entry);
  if (draft.entries.length > 20) {
    draft.entries.splice(0, draft.entries.length - 20);
  }
});
```

Use `push()` and `splice()` for shared arrays. See
[Data essentials](/docs/data/data-essentials/) for the complete mutation rules.
