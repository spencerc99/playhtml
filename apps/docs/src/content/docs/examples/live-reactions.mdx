## Send a payload

`eventPayload` travels with the event, and `onEvent` receives it:

```js
playhtml.dispatchPlayEvent({
  type: "reaction",
  eventPayload: { emoji: "🎉" },
});

// Every browser on the page, including yours, runs this.
function burst({ emoji }) {
  // float the emoji up
}

playhtml.init({
  events: {
    reaction: { type: "reaction", onEvent: burst },
  },
});
```

Each burst is a CSS animation that removes itself when it ends, so nothing
piles up.

See [Events](/docs/data/events/) for when to use events instead of shared data.
