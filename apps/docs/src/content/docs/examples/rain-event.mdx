## Listen, then dispatch

Register the event with `playhtml.init`, then dispatch it from a click. Every
connected browser, including yours, runs `onEvent`:

```js
playhtml.init({
  events: {
    rain: { type: "rain", onEvent: makeItRain },
  },
});

hydrant.addEventListener("click", () => {
  playhtml.dispatchPlayEvent({ type: "rain" });
});
```

The rain itself is plain DOM and CSS animation that removes itself after six
seconds.

See [Events](/docs/data/events/) for when to use events instead of shared data.
