playhtml makes HTML elements live and shared. Add an attribute like `can-toggle` to an element, and when anyone changes it, everyone on the page sees the change. The new state is saved for the next visitor too.

You don't need a backend. Elements sync through a server we run, or you can [run your own](/docs/reference/init-options/#host).

## Make your own

<Tabs syncKey="framework">
  <TabItem label="Vanilla HTML">

Add `can-toggle` and a unique `id` to an element, then add the playhtml script at the end of `<body>`:

```html
<body>
  <div id="my-light" class="light" can-toggle></div>

  <style>
    .light {
      width: 80px; height: 80px; border-radius: 50%;
      background: gold; filter: brightness(0.4);
    }
    /* can-toggle adds the "toggled" class when the light is on */
    .light.toggled {
      filter: brightness(1.2) drop-shadow(0 0 24px gold);
    }
  </style>

  <script type="module" src="https://unpkg.com/playhtml/dist/init.es.js"></script>
</body>
```

Open the page in two windows and click the light. It turns on in both.

The `id` is how playhtml tells elements apart, so each one needs its own. The script goes after your elements because it looks for them as soon as it loads.

**To pass options**, like showing everyone's cursors, import playhtml and call `init()` yourself instead of using the script tag above:

```html
<script type="module">
  import { playhtml } from "https://unpkg.com/playhtml";
  playhtml.init({ cursors: { enabled: true } });
</script>
```

  </TabItem>
  <TabItem label="React">

Install playhtml and its React package (React 16.8 and up):

```bash
npm install playhtml @playhtml/react
```

Wrap your app in `PlayProvider` once, then wrap an element in `CanToggleElement`. The element needs a unique `id`.

```tsx
import { PlayProvider, CanToggleElement } from "@playhtml/react";

export function App() {
  return (
    <PlayProvider>
      <CanToggleElement>
        <div id="my-light" className="light" />
      </CanToggleElement>
    </PlayProvider>
  );
}
```

`CanToggleElement` adds the `toggled` class when the light is on:

```css
.light {
  width: 80px; height: 80px; border-radius: 50%;
  background: gold; filter: brightness(0.4);
}
.light.toggled {
  filter: brightness(1.2) drop-shadow(0 0 24px gold);
}
```

Open the page in two windows and click the light. It turns on in both.

To pass options, like showing everyone's cursors, use `<PlayProvider initOptions={{ cursors: { enabled: true } }}>`.
