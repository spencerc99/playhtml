put the extension on this computer

For installation machines, before the store version is out. Takes about two minutes.

Download the extension

wwo-extension.zip — about 2 MB, Chrome and Edge

  1. Unzip it, and move the chrome-mv3 folder somewhere it can stay — Documents, not Downloads. Chrome loads it from that exact path every time it starts.
  2. Open chrome://extensions and turn on Developer mode (top right).
  3. Click Load unpacked and choose the chrome-mv3 folder.
  4. Finish the extension's setup. Set cursor collection to shared — local-only never reaches the screens — and pick this machine's cursor color.
  5. Open the extension's Settings, press Cmd+Shift+8, and check Installation mode. The frame, the live trace, and the sound start on the next page you load.

This build does not update itself. To update: download again, replace the folder's contents, and press the reload arrow on the extension's card in chrome://extensions.

Each machine gets its own participant identity and color the first time it runs, so its marks are its own.
